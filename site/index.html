How it works

Claude decides the layout. The engine draws it.

Claude only writes a compact JSON spec — rectangular rooms, doors, windows, fixtures. Everything geometric is deterministic code, so plans are clean, consistent and checkable.

Read the brief

Building type, target area, room list, region and units. Sketches are read for arrangement, proportions and written dimensions.

Write the spec

Zones, a circulation spine and a footprint grid come first; then rooms as rectangles on a 0.05 m grid, with doors, windows and fixtures.

Build the geometry

Walls on every room edge, exterior walls detected and thickened, openings cut, fixtures placed against walls and kept clear of door swings.

Check, fix, deliver

Nine MEP-readiness checks and a clash pass. Problems go back to the spec, never to the outputs, for at most two fix rounds.

villa.spec.json — what Claude writes
{
  "project": "UAE villa 4BR",
  "notes":   "Public wing north, private south.",
  "rooms":    [{"name":"Majlis", "type":"living", "x":0, "y":0, "w":6.5, "d":5.5}, …],
  "doors":    [{"from":"OUTSIDE", "to":"Lobby", "w":1.2, "side":"N"}, …],
  "windows":  [{"room":"Majlis", "side":"N", "w":1.5, "count":2}, …],
  "fixtures": [{"kind":"wc", "room":"Guest WC", "side":"N"}, …]
}

# then the engine takes over
node arplan.js build villa.spec.json --out out --name villa

What the engine guarantees

Metres, x east, y south. Exterior walls 0.25 m, interior 0.12 m. The same drawing engine powers AR Plan Studio, so plans move freely between the two.

  • Every room has a type, a door or opening, and bedrooms have an egress window
  • Bathrooms carry WC, basin and shower or tub; kitchens a sink
  • Water heater, AHU and electrical panel placed — the origins of every MEP run
  • Fixtures sit inside their room and clear of doorways and door swings
  • Fixtures carry their services (water, drain, gas, elec, hvac) into DXF, IFC and JSON

Outputs

Eight files per plan. All of them ready for the next tool.

Everything is written in metres with north up, so what you link into Revit lands where you expect it.

.svg / .png

The drawing

Room names, areas and exterior dimensions. The first-look image is sent as soon as the layout exists.

.dxf

AutoCAD R12 DXF

1 unit = 1 m, walls cut at openings, on standard layers.

.ifc

IFC4 model

Walls, doors, windows, a slab and an IfcSpace per room (Name = number, LongName = room name). Typed fixtures with an ARPlan_Fixture property set.

Interactive 3D

The plan lifts and the walls rise; then orbit, switch Plan / 3D, cut at 1.2 m, toggle fixtures.

.build.html / .mp4

Build replay

Rooms, walls, openings and fixtures appear with an elements-placed counter, then the MEP checks tick to a verdict. 1920×1080 video, about 14 s.

.full.mp4

2D-to-3D video

The whole story in one 1920×1080 clip: 2D build, crossfade, the plan lifting into 3D, a camera orbit, “IFC + DXF exported”.

.plan.json

Editable plan

Opens in AR Plan Studio with Import JSON. Fixtures carry room and services for the MEP step.

.report.md

Check report

Gross and conditioned area, room schedule, the nine MEP-readiness checks and the clash list.

In Revit: Insert ▸ Link CAD (DXF, import units metres) or Insert ▸ Link IFC. In Navisworks, append the IFC for coordination. Spaces, layers and fixture classes arrive ready for MEP modelling.

Conventions & limits

Built for GCC practice. Honest about scope.

Regional conventions

UAE / GCC is the default programme. Ask for another in the brief.

  • Majlis near the entrance with a guest WC, family living and dining, closed kitchen with pantry
  • Maid's room with its own bathroom, laundry, en-suite bedrooms with dressing rooms
  • Outdoor AC units, AHU, water heater and electrical panel placed as MEP origins
  • Egypt, US (IRC) and international conventions on request; metres or feet

Know the limits

Plans are concept-stage layouts for early coordination, not construction documents.

  • One level per plan; multi-storey briefs build one spec per level on the same grid
  • Rooms are rectangles — combine two with an opening for an L-shape
  • Check structure, code compliance and dimensions before issuing drawings
  • The 3D page needs WebGL and an internet connection for three.js
