# Code sources: Dubai (local only)

Put the downloaded files in this folder. Keep them out of the public repo: add `docs/sources/*` (except this README) to `.gitignore`.
The Dubai documents are free from the government sites, but they are still official documents, not ours to redistribute.

| Save as | Document | Where to get it |
|---|---|---|
| `dubai-building-code-2021.pdf` | **Dubai Building Code 2021 (English)**, the full edition, around 1,000 pages, not the 17-page summary | Dubai Municipality: https://www.dm.gov.ae (search "Dubai Building Code"), or the Dubai Building Code page on the DM / DDA sites |
| `dewa-electrical-2017.pdf` | **DEWA Regulations for Electrical Installations 2017** | https://dewa.gov.ae/-/media/DEWA_Regulations_for_Electrical_Installations_2017_Edition.ashx |
| `dewa-dbc-circular.pdf` | DEWA circular on the DBC (which electrical clauses moved into the DBC) | https://dewa.gov.ae/-/media/Files/Consultants-and-Contractors/Circulars/Dubai-Building-Code-Circular-EN.ashx |
| `uae-fire-code-2018.pdf` | **UAE Fire & Life Safety Code of Practice 2018** | Dubai Civil Defence / UAE Civil Defence website (search "UAE Fire and Life Safety Code 2018"). Older copies are 2011 or 2017; we need **2018**. |
| `dm-permit-faq.pdf` (optional) | DM FAQ on building permit procedures | https://dmpmedia.dm.gov.ae/uploads/2023/09/FAQ-for-Buildings-Permit-Procedures-and-Regulations-eng-1.pdf |
| `hassantuk.txt` (optional) | Note or link on the villa smoke-detector / Hassantuk requirement | Civil Defence or Hassantuk site |
| `affection-plan-sample.pdf` (optional) | One real or sample affection plan / DCR for a villa plot | Your own projects (it gives setbacks and coverage for K-10 and K-11) |

**Most important first:** the DBC 2021 PDF. Almost every K, P and V rule and some E rules come from it.

To read the PDFs, Claude needs a PDF text tool on this PC (for example `pip install pypdf` or poppler). Claude will ask before installing anything.
